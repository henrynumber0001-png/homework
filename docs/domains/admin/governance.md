# 后台运营治理

## 1. 用户治理

- 查询用户和账号状态。
- 执行封禁、解封等用户状态动作。
- 限制或恢复用户的社区能力。
- 高风险动作要求二次认证并记录原因。

## 2. 社区治理

- 查询 Hit 和相关社区内容。
- 隐藏、恢复或删除违规内容。
- 保留必要的操作轨迹，避免治理动作失去审计依据。

## 3. 会员与订单运营

- 查询会员状态、权益变更记录和订单。
- 执行受控的会员调整。
- 维护会员套餐，但不直接改写历史订单价格快照。

## 4. 平台治理

- 管理员邀请、状态、角色和权限。
- 题库数据范围控制。
- 高风险操作二次认证。
- 管理操作日志查询与追溯。

详细权限、请求字段和动作约束参见[管理端 API](../../reference/admin-api.md)。
