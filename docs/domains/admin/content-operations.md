# 后台内容运营

## 1. 功能目标

内容运营负责把分类、题库和题目安全地维护并发布到用户端。

## 2. 功能范围

- 分类树维护与选择。
- 题库创建、编辑、发布、下架和删除。
- 题目创建、编辑、排序、发布、下架和删除。
- 选择题选项和题目图片维护。
- Excel 模板下载、上传预检、错误报告和确认导入。

## 3. 业务保护

- 管理员必须具备对应权限码和题库数据范围。
- 可编辑资源通过 `version` 进行乐观锁校验。
- 高风险动作记录操作原因并写入审计日志。
- 导入任务区分预检与确认，错误数据不能直接落库。
- 题库满足发布条件后才允许发布。
