# 题库内容发布

## 1. 功能目标

内容发布连接后台维护和用户端可见内容，确保不完整、无权限或状态不正确的题库和题目不会对用户开放。

## 2. 标准流程

```text
创建题库 → 手动创建或 Excel 导入题目 → 校验内容 → 调整顺序
         → 发布题目 → 发布题库 → 用户端可见
```

## 3. 核心规则

- 题目创建和编辑必须在具体题库工作台中进行。
- 发布题库前至少存在满足发布条件的题目。
- 题型、答案和选项组合必须通过服务端校验。
- 题目顺序由后台显式维护，不依赖创建时间。
- 图片先上传至临时对象目录，保存题目时再绑定正式对象。
- 后台写操作同时受权限码、题库数据范围和乐观锁版本保护。
