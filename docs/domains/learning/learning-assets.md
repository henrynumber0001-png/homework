# 学习资产

## 1. 定义

学习资产是用户在做题过程中形成、仅服务于个人学习的数据，不属于公开主页或社区内容。

## 2. 资产类型

| 类型 | 来源 | 主要用途 |
| --- | --- | --- |
| 错题 | 认证练习或考试判题 | 针对性复习 |
| 收藏题目 | 用户主动收藏题目 | 建立个人题目清单 |
| 题目笔记 | 用户对题目保存笔记 | 记录理解和补充信息 |
| 答题记录 | 用户提交答案 | 回顾历史答案与解析 |
| 学习日历 | 学习心跳按日聚合 | 展示持续学习情况 |
| 题库统计 | 完成和作答行为聚合 | 展示完成状态与正确率 |

## 3. 核心规则

- 资产查询只能返回当前登录用户的数据。
- 错题、收藏题目和笔记按题库聚合，再进入题目列表和详情。
- 学习心跳用于统计活跃学习时长，不替代答案保存。
- 公开主页不得返回错题、收藏题目、笔记等私有学习数据。

## 4. 接口与实现

- 个人题库：`/api/app/user-center/wrong-question-*`、`favorite-question-*`、`note-*`
- 学习活动：`/api/app/learning-activity/heartbeat`、`calendar`
- 数据实体：`UserQuestionAnswer`、`UserFavoriteQuestion`、`UserQuestionNote`、`UserLearningStatDaily`
