# 做题模式

## 1. 面试题练习

- 用户提交简答内容。
- 服务端保存答题记录并返回 AI 评价和参考答案。
- 用户可以基于当前题目、答案和解析继续 AI 追问。
- AI 会话按用户和题库复用，并可由用户关闭。

## 2. 认证题练习

- 用户逐题提交单选、多选等客观题答案。
- 提交后立即判题并返回答案解析。
- 错误答案进入用户的错题沉淀。

## 3. 认证考试

- 服务端创建考试场次并确定有效期。
- 考试过程中保存临时答案，不逐题展示正确答案。
- 交卷时统一判题并生成结果。
- 超时、重复提交和不属于当前用户的场次必须被拒绝。

## 4. 完成与复习

- 完成题库后更新用户题库完成状态和复习数据。
- 面试题和认证题使用各自的复习读取接口。
- 清除学习记录是用户主动操作，应明确目标题库并进行确认。

具体接口参见[API 总览](../../reference/api-overview.md)。
