# HomeWork 产品概览

## 1. 产品定位

HomeWork 是面向题库学习和备考的 Web 平台。产品主链路是“发现题库 → 练习或考试 → 查看反馈 → 沉淀错题、收藏和笔记 → 持续复习”。社区、消息、公开主页和会员体系围绕这条学习主链路提供交流与增值能力。

## 2. 用户角色

### 普通用户

- 注册、登录并维护个人资料。
- 浏览面试题库或认证题库。
- 进行练习、考试、复习和 AI 追问。
- 管理错题、收藏、笔记和学习记录。
- 发布 Hit，与其他用户互动、关注或私信。
- 购买和管理 Premium / Premium Plus。

### 管理员

- 通过邀请激活管理账号并独立登录。
- 维护分类、题库、题目、图片和发布状态。
- 使用 Excel 批量导入题目。
- 管理用户、社区内容、会员、管理员权限和审计日志。

## 3. 产品能力结构

```text
HomeWork
├── 学习主链路
│   ├── 题库内容
│   ├── 学习与做题
│   └── 学习资产
├── 用户体验
│   ├── 用户与账号
│   ├── 首页与内容发现
│   └── 社区与社交
├── 商业能力
│   └── 会员与交易
└── 运营能力
    ├── 内容运营
    ├── 用户与社区治理
    └── 权限与审计
```
